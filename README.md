# 🐍 Python-Starter

### 📝 Descrição
Repositório dedicado ao meu aprendizado de Python, contendo exercícios de lógica de programação, matemática aplicada e pequenos projetos de prática.

### 🚀 O que estou estudando:
* *Lógica e Matemática:* Operações aritméticas, conversão de tipos e manipulação de variáveis.
* *Estruturas de Dados:* Introdução ao uso de listas e sorteios aleatórios.
* *Módulos e Bibliotecas:* Experiência com bibliotecas nativas (math, random) e externas (pygame).

### 📂 Projetos Práticos Incluídos:
* *Tabuada.py*: Tabuada automática gerada a partir de uma entrada do usuário.
* *Conversor de moedas.py*: Conversor de moedas (Real para Dólar e Euro) com formatação de casas decimais.
* *Cálculo de Área e Tinta.py*: Calculadora de área de parede e estimativa de tinta necessária.
* *Descontos.py*: Script para cálculo de descontos em produtos (5% OFF).
* *Aumentos.py*: Sistema para cálculo de aumento salarial (15%).
* *Sen,Cos,Tang.py*: Calculadora trigonométrica (Seno, Cosseno e Tangente) usando o módulo math.
* *Sorteio de Alunos.py*: Sistema de sorteio aleatório de nomes utilizando Listas e o módulo random.
* *Player de Áudio.py*: Player de áudio básico para execução de arquivos MP3 utilizando a biblioteca pygame.
* *Gerador de senhas.py*: Script para criação de senhas aleatórias e seguras.

### 🛠️ Ferramentas
* *Linguagem:* Python 3.x
* *IDE:* PyCharm
* *Controle de Versão:* Git / GitHub
